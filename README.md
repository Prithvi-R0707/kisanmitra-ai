# KisanMitra AI - Digital Farming Companion
Multilingual AI assistant for Indian smallholder farmers with voice, offline sync, and agronomy tools.

### Quick Start
1. Install: `npm run install:all`
2. Seed Demo Farmer: `npm run seed` (Ramesh Kumar, +91 9876543210, Tamil Nadu)
3. Launch: `npm run dev` (Frontend: `http://localhost:5173`, Backend: `http://localhost:5000`)

### Features
11 Indian Languages • Soil Wizard • Gemini Vision Diagnosis • Mandi Rates • Budget & Offline Sync
